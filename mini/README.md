# cim-anonymizer

## Образцы большого CIM/RDF XML

Исходный файл `data/input.xml` весит ~921 МБ и содержит ~9 млн элементов.
Для разработки и отладки обезличивания созданы компактные образцы, которые
потоково собираются из оригинала и сохраняют его структуру.

| Файл | Размер | Что внутри |
|---|---:|---|
| `data/input_sample.xml` | ~4,3 МБ | 1673 примера — по одному на каждый уникальный структурный отпечаток. Покрывает **все** 263 класса, 2638 путей и все имена атрибутов оригинала. |
| `data/input_sample_mini.xml` | ~1,6 МБ | 263 примера — по одному самому полному объекту на класс. Удобно быстро открыть в VSCode. Покрывает 2453 из 2638 путей. |
| `data/input_sample_report.txt` | ~0,3 МБ | Отчёт по оригиналу: пространства имён, классы, количество объектов, все пути элементов и их атрибуты. |

### Генерация полного образца

```bash
uv run python mini/make_sample.py \
  --max-per-tag 300 \
  --max-children 2 \
  --output samples/input_sample.xml \
  --report samples/input_sample_report.txt
```

Скрипт использует `lxml.iterparse` и не загружает исходный файл в память.
Полный проход по 921 МБ занимает около минуты.

Параметры:

* `--max-per-tag` — максимум примеров на один верхнеуровневый тег
  (по умолчанию 10; для полного покрытия нужно значение больше максимального
  числа уникальных структур, сейчас это 217);
* `--max-children` — сколько однотипных дочерних элементов оставлять внутри
  примера (структура при этом не теряется);
* `--stats-only` — только собрать отчёт, образец не писать.

### Мини-образец

```bash
uv run python mini/make_mini.py
```

Скрипт читает `samples/input_sample.xml` и для каждого класса оставляет объект
с самым большим поддеревом.

### Проверка покрытия

```bash
uv run python mini/validate_sample.py \
  samples/input_sample_report.txt \
  samples/input_sample.xml
```

Проверяются корневой тег, пространства имён, все верхнеуровневые теги, все пути
элементов и все имена атрибутов на каждом пути.

### Важно

Образцы **не обезличены**: в них сохранены исходные значения `rdf:ID`,
`rdf:resource`, имён и других атрибутов. Они предназначены только для
структурного тестирования и не должны публиковаться или передаваться третьим
лицам.
